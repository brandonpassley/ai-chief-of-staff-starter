# {{YEAR}} Annual Plan & OKRs

## How Claude Uses This File

This is the **strategy layer for the current year** — what success looks like by Dec 31. Loaded when:
- Planning quarters and setting Rocks
- Doing mid-year or year-end reviews
- The user makes a tradeoff that affects yearly outcomes
- Setting the KPI Scoreboard targets that feed `scorecard.md`

When empty, run the user through an OKR conversation. Push for **specific, measurable, bounded** targets. Vague OKRs are useless — they let everything count as progress.

## Coaching Standards

A strong annual plan has:
- **3-6 Objectives** (not 12 — focus is the point)
- **Each Objective has 3-5 Key Results** that are measurable + dated
- **A KPI Scoreboard** with annual target + quarterly actuals for each major metric
- **Priorities by Quarter** so the year has phasing, not just a single dump

When pushing back on weak OKRs:
- "Grow the business" → not an Objective. Ask: by how much? What dimension (revenue, customers, profitability, brand)?
- "Get more leads" → KR? Then how many? By when? Through what channel?
- "Hire a team" → ask: which roles? When? What problem does each solve?
- KRs without numbers → reject. KRs are quantitative by definition.
- "Be more strategic" → meaningless. Ask: what decision will you make this year that you wouldn't have made last year?

Each Objective should ladder up to a Life Plan destination. If you can't draw the line from this year's Objective to the 5-year destination, ask why this is on the list.

## Review Cadence

- **End of each quarter** — review what hit, what missed; carry forward what works, kill what doesn't; set next quarter's Rocks
- **Mid-year (June 30)** — honest checkpoint; adjust KRs if reality has shifted
- **End of year (Dec 31)** — full retrospective; set next year's annual plan

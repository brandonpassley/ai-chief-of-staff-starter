# Scorecard

## How Claude Uses This File

The **operations layer** — the user's real numbers per week and per month. Source of truth for:
- `/weekly-wrap-up` — fill this week's row with actuals
- `/weekly-plan` — last week's numbers inform next week's targets
- `/day` Coach's Pulse — flag drift if a metric is trending down
- Any "where am I actually" conversation — read from this file

When empty, walk the user through defining the metrics that matter for THEIR business. Push back if metrics aren't measurable, aren't tracked, or aren't owned.

## Coaching Standards

A strong scorecard has:
- **5-10 weekly metrics** (not 30 — focus matters)
- **Each metric has a target + owner**
- **Mix of leading + lagging indicators** — but MOSTLY leading (controllable activity)
- **Activity metrics dominant** — outcomes are downstream of activity
- **Filled in every Friday** — non-negotiable cadence

When pushing back on weak metrics:
- "Customer satisfaction" → not measurable as-is. Ask: NPS? CSAT score? Reviews? Pick one.
- "Sales" → too broad. Ask: deals closed? MRR? Proposals sent? Discovery calls?
- "Health" → not granular. Ask: workouts/week? Sleep hours? Macros tracked?
- Metrics without targets → reject. A metric without a number is data, not a scorecard.

Each metric should ladder up to a Rock or a Life Plan principle. If a metric doesn't connect to anything, ask why it's being tracked.

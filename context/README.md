# context/

This folder holds your **Strategy** and **Operations** layers — everything beyond identity.

| File | Layer | Purpose |
|---|---|---|
| `life-plan.md` | Strategy | 5/10-year vision, wealth code, identity |
| `annual-plan.md` | Strategy | Yearly OKRs + KPI scoreboard |
| `rocks.md` | Strategy | Quarterly EOS Rocks |
| `scorecard.md` | Operations | Weekly metrics tracker |
| `people.md` | Operations | Relationship intelligence (named individuals) |
| `expansion-roadmap.md` | Reference | What to add to your CoS as you grow |
| `dashboard-spec.md` | Reference | Standards for your visual dashboard |
| `clients/` | Operations | One file per client (when you have several) |
| `projects/` | Operations | One file per major engagement |
| `integrations/` | Operations | Tool-specific usage opinions (one per connected MCP) |

**You rarely edit these files by hand.** Tell Claude what's changed in conversation; Claude writes the file.

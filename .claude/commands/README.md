# .claude/commands/

Slash commands — repeatable rituals your CoS runs on demand.

| Command | When you use it |
|---|---|
| `/day` | Every morning |
| `/weekly-plan` | Sunday or Monday morning |
| `/weekly-wrap-up` | Friday afternoon |
| `/debrief` | After any meeting / call |
| `/dashboard` | Anytime — build or update your visual CoS dashboard |
| `/grow` | When you want a suggestion for the next thing to add |

**To add a new command:** tell Claude *"help me build a /[name] command for [purpose]."* Claude drafts the file. You review, save.

Commands are markdown files. Claude reads them when you type the slash command. You can edit them anytime — or ask Claude to edit them through conversation.
